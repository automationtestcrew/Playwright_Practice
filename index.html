1. Intro & Installation

1.1 Selenium vs Playwright

▶

Selenium vs Playwright - The Ultimate Comparison

Understand why Playwright is the modern alternative to Selenium. Compare architecture, speed, reliability, and developer experience.

Watch on YouTube ↗

Deep Dive: Why Playwright Wins

  • Architecture: Selenium uses the WebDriver API (JSON Wire Protocol) which acts as a middleman. Playwright communicates directly with browsers using the Chrome DevTools Protocol (CDP) and socket connections, making it significantly faster and more reliable.
  • Auto-waiting: Playwright performs a range of actionability checks (visibility, stability, enabled) before performing actions. No more Thread.sleep() or complex explicit waits!
  • Execution Speed: Due to its modern architecture, Playwright can run tests up to 3x faster than Selenium.
  • Tooling: Playwright comes with the Trace Viewer (for time-travel debugging), Codegen (to record tests), and Inspector out of the box.
  • Context Isolation: Playwright uses BrowserContexts to provide complete isolation between tests with zero overhead—it's like opening an Incognito window for every test.
  • Language Support: While Selenium has broader language support, Playwright's TypeScript/JavaScript integration is best-in-class, with first-party support for Python, Java, and .NET.

2. Basics

2.1 First Script

▶

First Script - Launching Your First Browser

Write your very first Playwright test from scratch. Understand the hierarchy of Browser, BrowserContext, and Page.

Watch on YouTube ↗
  • Browser Fixture: Access the global browser instance.
  • BrowserContext: Create isolated environments (like incognito windows) using browser.newContext().
  • Page Object: Open new tabs or pages within a context using context.newPage().
  • Wait Logic: Using page.waitForTimeout() to pause execution (useful for debugging/learning).
import { test } from '@playwright/test';

test("Launch Browser Script", async({ browser }) => {

    // Launch the Browser --> Context (Incognito) --> Page (Tab)
    const context = await browser.newContext();
    const page = await context.newPage();

    // Pause for 2 seconds to see the browser launch
    await page.waitForTimeout(2000);

});

2.2 Browser Actions

▶

Browser Actions

Master all essential browser interactions — clicking, typing, selecting, hovering, dragging, file uploads, and keyboard shortcuts.

Watch on YouTube ↗
  • page.goto(): Navigate to any URL
  • page.title(): Get the current page title
  • page.url(): Retrieve the current URL
  • page.reload(): Refresh the current page
  • page.goBack() / .goForward(): Navigate history
import { test,expect } from '@playwright/test';

test("Launch Browser Script",async({page}) => {

    await page.waitForTimeout(2000);

    await page.goto("https://www.instagram.com/");

    const pageTile = await page.title();
    const currentUrl =  await page.url();

    console.log(`Page Tile ${pageTile}`)
    console.log(`Current URL ${currentUrl}`)

    await page.waitForTimeout(2000);

    await page.goto("https://www.facebook.com/")

    await page.waitForTimeout(2000);

    await page.reload();
    await page.waitForTimeout(2000);

    await page.goBack();
    await page.waitForTimeout(2000);

    await page.goForward();
    await page.waitForTimeout(2000);
})

2.3 Basic Assertions

▶

Basic Assertions

Learn Playwright's powerful expect() API. Use auto-retrying assertions that wait for conditions to become true, making your tests stable.

Watch on YouTube ↗
  • expect(actual).toEqual(expected): Direct value comparison
  • expect.soft(): Test continues even if assertion fails
  • Custom Failure Messages: Pass a string as the second argument to identify failures
  • Page Metadata: Assertions on page.title() and page.url()
import { test,expect } from '@playwright/test';

test("Launch Browser Script",async({page}) => {

    await page.waitForTimeout(2000);

    await page.goto("https://www.instagram.com/");

    const pageTile = await page.title();
    const currentUrl =  await page.url();

    //actual == expected 
    expect.soft(pageTile,"Title is not matching").toEqual("facebook");

    expect(currentUrl).toEqual("https://www.instagram.com/")

    await page.waitForTimeout(2000);

    await page.goto("https://www.facebook.com/")

    await page.waitForTimeout(2000);
})

Quick Reference Table

Locator HTML it targets Best For Avoid When
getByRole aria roles, <button>, <a>, <h1> Interactive elements, a11y Never (always prefer this)
getByLabel <label for="">, aria-label Form inputs, checkboxes Non-form elements
getByPlaceholder placeholder="text" Search bars, inline inputs A label is available
getByText visible text content Paragraphs, static text Text changes frequently
getByAltText alt="text" Images, SVG with alt Decorative images
getByTitle title="text" Tooltips, icon-only buttons aria-label is present
getByTestId data-testid="id" Dynamic UI, no semantics Semantic HTML exists
